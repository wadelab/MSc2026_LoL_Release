# Archived journal variants

These journal-specific variants of the manuscript are retired. The active
submission target is the **rsos** (Royal Society Open Science) variant in the
parent `journal_variants/` directory.

- `lol_circadian_rhythms_bit.*` — Big Data & Society
- `lol_circadian_rhythms_chb.*` — Computers in Human Behavior (American spelling)
- `lol_circadian_rhythms_gigascience.*` — GigaScience

The `.qmd` sources here use image paths (`../../results/...`) relative to their
original `journal_variants/` location. To rebuild one, move it back up one level
first, or fix the relative paths for this deeper directory.

Their numbers were current as of the archive date and match the rsos variant and
the main paper at that point.
