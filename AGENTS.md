# AGENTS

## Working Conventions

- Use `uv` whenever possible for Python environment and dependency workflows.
- Prefer `uv`-based commands over direct `pip` or `python -m pip` when both are viable.
- In this repository, `CAP` means: **commit and push**.

## CAP Definition

When asked to CAP:

1. Create a commit with the requested changes.
2. Push the current branch to the configured remote.
